# 3D Printing Designs

Printable designs (lots of IKEA SKÅDIS pegboard holders for audio and camera gear), with the parametric source for each.

Every design is generated by a script you can edit. Each print carries an engraved `JRJP-…` serial number, set by `SERIAL` at the top of its script.
