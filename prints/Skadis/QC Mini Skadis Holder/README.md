# QC Mini SKÅDIS Holder

SKÅDIS stand for storing a Neural DSP Quad Cortex Mini upright: standing on its front edge, the touchscreen facing you the right way up, rear jacks on top.

![QC Mini SKÅDIS Holder](images/preview.png)

> Not yet test-printed in this exact version.

## Files

- `qc_mini_holder_JRJP-QCM-0001.3mf` - 3MF (open in your slicer)
- `qc_mini_holder_JRJP-QCM-0001.stl` - STL
- `qc_mini_holder.py` - source

## Print settings

- **Material:** PETG
- **Supports:** tree, build plate only (already set in the 3MF)
- **Orientation:** as exported
- **Notes:** Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

## Serial number

Each print carries an engraved serial number (JRJP-QCM-0001). The `SERIAL` setting at the top of the source controls it.

## Changing it

The model is generated by the Python script with [build123d](https://github.com/gumyr/build123d). Edit the numbers at the top and run it:

```bash
pip install build123d trimesh
python qc_mini_holder.py
```
