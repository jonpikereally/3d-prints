# EW-D Bodypack SKÅDIS Holder (MIC 5-8)

SKÅDIS holder for four more Sennheiser EW-D / EW G4 bodypacks side by side, labelled MIC 5-8.

![EW-D Bodypack SKÅDIS Holder (MIC 5-8)](images/preview.png)

SKÅDIS holder for four more Sennheiser EW-D / EW G4 bodypacks side by side, labelled MIC 5-8. Identical to the MIC 1-4 holder except for the labels.

> Not yet test-printed in this exact version.

## Files

- `ewd_bodypack_holder_5-8_JRJP-EWB-0004.3mf` - 3MF (open in your slicer)
- `ewd_bodypack_holder_5-8_JRJP-EWB-0004.stl` - STL
- `ewd_bodypack_holder_5-8.py` - source

## Print settings

- **Material:** PETG
- **Supports:** tree, build plate only (already set in the 3MF)
- **Orientation:** as exported
- **Notes:** Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

## Serial number

Each print carries an engraved serial number (JRJP-EWB-0004). The `SERIAL` setting at the top of the source controls it.

## Changing it

The model is generated by the Python script with [build123d](https://github.com/gumyr/build123d). Edit the numbers at the top and run it:

```bash
pip install build123d trimesh
python ewd_bodypack_holder_5-8.py
```
