DESCRIPTION
SKÅDIS ring tool holder, modelled on IKEA's black SKÅDIS tool holder 905.699.45: a short spine on the board with the hook and peg, and a flat ring right beside it that a screwdriver, scissors, a hammer handle or a glue gun drops through.

Each print carries an engraved serial number (JRJP-TLH-0002). The `SERIAL` setting at the top of the source controls it.

Print settings:
- Material: PETG
- Supports: tree, build plate only (already set in the 3MF)
- Orientation: as exported
- Notes: Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

Source (editable Python/OpenSCAD): https://github.com/jonpikereally/3d-prints/tree/main/prints/Skadis/Generic%20Skadis%20Designs/Tool%20Holder
