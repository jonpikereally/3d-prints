DESCRIPTION
SKÅDIS holder for a Zoom H6studio, standing bare with its mic capsule on top, in a cup that holds the bottom of the body.

Each print carries an engraved serial number (JRJP-H6S-0001). The `SERIAL` setting at the top of the source controls it.

Print settings:
- Material: PETG
- Supports: tree, build plate only (already set in the 3MF)
- Orientation: as exported
- Notes: Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

Source (editable Python/OpenSCAD): https://github.com/jonpikereally/3d-prints/tree/main/prints/Skadis/H6studio%20Skadis%20Holder
