# Instax Wide 300 SKÅDIS Holder

SKÅDIS shelf for storing a Fujifilm Instax Wide 300, sitting on its base with the lens facing out.

![Instax Wide 300 SKÅDIS Holder](images/preview.png)

> Not yet test-printed in this exact version.

## Files

- `instax_wide_holder_JRJP-IW3-0001.3mf` - 3MF (open in your slicer)
- `instax_wide_holder_JRJP-IW3-0001.stl` - STL
- `instax_wide_holder.py` - source

## Print settings

- **Material:** PETG
- **Supports:** tree, build plate only (already set in the 3MF)
- **Orientation:** as exported
- **Notes:** Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

## Serial number

Each print carries an engraved serial number (JRJP-IW3-0001). The `SERIAL` setting at the top of the source controls it.

## Changing it

The model is generated by the Python script with [build123d](https://github.com/gumyr/build123d). Edit the numbers at the top and run it:

```bash
pip install build123d trimesh
python instax_wide_holder.py
```
