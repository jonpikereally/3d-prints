# Scarlett 4i4 SKÅDIS Holder

SKÅDIS holder for a Focusrite Scarlett 4i4 (4th Gen) standing on its rear panel, knobs facing up.

![Scarlett 4i4 SKÅDIS Holder](images/preview.png)

> Not yet test-printed in this exact version.

## Files

- `scarlett_4i4_holder_JRJP-4I4-0002.3mf` - 3MF (open in your slicer)
- `scarlett_4i4_holder_JRJP-4I4-0002.stl` - STL
- `scarlett_4i4_holder.py` - source
- `scarlett_4i4_holder_fit_test.py` - source

## Print settings

- **Material:** PETG
- **Supports:** tree, build plate only (already set in the 3MF)
- **Orientation:** as exported
- **Notes:** Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

## Serial number

Each print carries an engraved serial number (JRJP-4I4-0002). The `SERIAL` setting at the top of the source controls it.

## Changing it

The model is generated by the Python script with [build123d](https://github.com/gumyr/build123d). Edit the numbers at the top and run it:

```bash
pip install build123d trimesh
python scarlett_4i4_holder.py
```
