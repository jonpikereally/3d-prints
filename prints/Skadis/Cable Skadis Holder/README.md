# Cable SKÅDIS Holder

SKÅDIS hanger for coiled cables: two arms 80 mm apart, each with a 15 mm lip at the end.

![Cable SKÅDIS Holder](images/preview.png)

> Not yet test-printed in this exact version.

## Files

- `cable_holder_JRJP-CBL-0001.3mf` - 3MF (open in your slicer)
- `cable_holder_JRJP-CBL-0001.stl` - STL
- `cable_holder.py` - source

## Print settings

- **Material:** PETG
- **Supports:** tree, build plate only (already set in the 3MF)
- **Orientation:** as exported
- **Notes:** Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

## Serial number

Each print carries an engraved serial number (JRJP-CBL-0001). The `SERIAL` setting at the top of the source controls it.

## Changing it

The model is generated by the Python script with [build123d](https://github.com/gumyr/build123d). Edit the numbers at the top and run it:

```bash
pip install build123d trimesh
python cable_holder.py
```
