# Treedix USB Tester SKÅDIS Holder

SKÅDIS storage cup for a Treedix TRX5-0816 USB cable tester (2.4-inch colour screen).

![Treedix USB Tester SKÅDIS Holder](images/preview.png)

> Not yet test-printed in this exact version.

## Files

- `treedix_holder_JRJP-UCT-0002.3mf` - 3MF (open in your slicer)
- `treedix_holder_JRJP-UCT-0002.stl` - STL
- `treedix_holder.py` - source
- `treedix_holder_fit_test.py` - source

## Print settings

- **Material:** PETG
- **Supports:** tree, build plate only (already set in the 3MF)
- **Orientation:** as exported
- **Notes:** Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

## Serial number

Each print carries an engraved serial number (JRJP-UCT-0002). The `SERIAL` setting at the top of the source controls it.

## Changing it

The model is generated by the Python script with [build123d](https://github.com/gumyr/build123d). Edit the numbers at the top and run it:

```bash
pip install build123d trimesh
python treedix_holder.py
```
