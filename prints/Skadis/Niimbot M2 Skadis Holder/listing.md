SKÅDIS shelf for storing a Niimbot M2 label printer, lying sideways (its long side along the board).

Each print carries an engraved serial number (JRJP-NM2-0001). The `SERIAL` setting at the top of the source controls it.

Print settings:
- Material: PETG
- Supports: tree, build plate only (already set in the 3MF)
- Orientation: as exported
- Notes: Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

Source (editable Python/OpenSCAD): https://github.com/jonpikereally/3d-prints/tree/main/prints/Skadis/Niimbot%20M2%20Skadis%20Holder
