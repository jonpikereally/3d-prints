# Hammer SKÅDIS Holder

SKÅDIS fork for a hammer: the handle goes in the front-open slot and the head rests across the tines.

![Hammer SKÅDIS Holder](images/preview.png)

> Not yet test-printed in this exact version.

## Files

- `hammer_holder_JRJP-HAM-0001.3mf` - 3MF (open in your slicer)
- `hammer_holder_JRJP-HAM-0001.stl` - STL
- `hammer_holder.py` - source

## Print settings

- **Material:** PETG
- **Supports:** tree, build plate only (already set in the 3MF)
- **Orientation:** as exported
- **Notes:** Designed on a Snapmaker U1; the 3MF opens in Bambu Studio, OrcaSlicer and PrusaSlicer.

## Serial number

Each print carries an engraved serial number (JRJP-HAM-0001). The `SERIAL` setting at the top of the source controls it.

## Changing it

The model is generated by the Python script with [build123d](https://github.com/gumyr/build123d). Edit the numbers at the top and run it:

```bash
pip install build123d trimesh
python hammer_holder.py
```
